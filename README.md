# 酸橙来信 · 个人介绍与感受版

双击 index.html 浏览，无需安装依赖。使用用户提供的明日方舟主题图片作为主视觉。非官方主题个人页面，未部署到公网。

## 页面内容

自我介绍、原创 SVG 示意头像（非真实肖像）、三张可切换的心情卡、三封可筛选阅读的手记、写给访客的信、本地便签。

文案是结合对话主题撰写的第一人称初稿，不代表用户已确认全部感受或偏好。没有加入姓名、联系方式、医疗信息或私人创伤经历。正式公开前，可逐句改成自己真正想说的话。

## 动态效果

- 短笺开场自动向上退场，天空缓慢展开，标题逐行浮现。
- 滚动时卡片与信纸入场；心情切换与弹窗有轻量过渡。
- 装饰星光和云漂浮；右下角可暂停动效。
- 遵循系统减少动态效果偏好；Tab 或 Escape 可跳过开场。
- 无 JavaScript 时正文可读，开场由 CSS 自动结束。

## 修改位置

- index.html：站名、介绍、手记摘要、访客信。
- script.js：articles 是手记正文，feelingCards 是心情文案。
- style.css：基础主题；personal.css：个人版布局与动画。
- assets/summer-sky.jpg：用户提供的主题图片，非原创插画。

旧鹈鹕页面保留在 assets/pelican-bike.html，不再作为首页主内容。便签只保存在当前浏览器，不上传或分享给访客。

浏览器安全策略禁止工具自动打开本地页面，因此尚未完成视觉验收。
